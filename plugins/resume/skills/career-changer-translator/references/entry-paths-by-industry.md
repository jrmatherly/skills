# Entry paths by target industry

Common routes in, by the kind of role the user is coming from, and bridge
activities that add credible experience. Treat these as starting points:
confirm that a named certification or route is current and valued in the
user's market before recommending it.

## Into tech

| Entry point | Comes from |
| --- | --- |
| Customer success | Any client-facing role |
| Technical project manager | Any project management role |
| Sales / account executive | Any sales role |
| Product management | Domain expertise |
| Technical writing | Any writing role |

Bridge activities:

- Learn SQL, basic coding or the tools the target role uses.
- Earn a vendor certification (for example Google, Salesforce or AWS).
- Build personal projects.
- Attend tech meetups.
- Volunteer for tech nonprofits.

## Into finance

| Entry point | Comes from |
| --- | --- |
| Operations | Any process-oriented role |
| Compliance | Any regulated industry |
| Client services | Relationship roles |
| Analysis | Any analytical role |

Bridge activities:

- Excel or financial modeling certifications.
- CFA or CFP study.
- Financial analysis courses.
- Industry networking.

## Into healthcare

| Entry point | Comes from |
| --- | --- |
| Healthcare administration | Any administrative role |
| Medical sales | Any sales role |
| Health IT | Any tech role |
| Patient advocacy | Customer service |

Bridge activities:

- Healthcare certifications.
- HIPAA training.
- Study of the healthcare industry and how it operates.
- Volunteering at hospitals.
