# Profile optimization report

Respond in this structure. Write "Not provided" for anything that could not
be assessed (photo, banner, connection count) instead of guessing. A number the user has not confirmed appears in the
optimized text as a bracketed placeholder such as `[N]`, never as a figure,
and is listed under "To confirm".

```markdown
# LinkedIn profile optimization

## Current profile assessment

**Completeness:** [X of Y checklist items met, as a percentage]
**Searchability score:** [X/10, with one line on why: how well target
keywords are covered in the headline, About, Experience and Skills]
**Key issues:** [list]

## Optimized sections

### Headline

**Current:** [their current headline]
**Optimized:** [new headline with keywords] ([N] characters)

### About section

[Full optimized About section text] ([N] characters)

### Experience improvements

**[Company name]**

- Add: [suggested additions]
- Modify: [suggested changes]
- Media to add: [suggestions]

### Skills to add

[Skills to add for the target roles, and the order to put the most important ones first]

### Keywords integrated

[Keywords added throughout the profile, and where]

## To confirm

[Estimates, assumptions or facts not found in the user's material; "None" if
there are none]

## Action items

1. [ ] Update headline
2. [ ] Rewrite About section
3. [ ] Update current role description
4. [ ] Add [X] skills
5. [ ] Request [X] recommendations
6. [ ] Add featured content
7. [ ] Upload professional photo
```

Keep only the action items that apply, and add any setting changes
(Open to Work, visibility) the assessment calls for.
