# Section recommendations template

Use this shape. When the user asked about one section only, keep the header
and that section's block and drop the rest.

```markdown
# Resume section recommendations

## For: [User's situation and target role]

### Recommended section order

1. [Section] - [Why]
2. [Section] - [Why]

### Section details

#### Professional summary

**Recommendation:** [Include / Skip] - [reason]
**Draft:**
[Written summary, if recommended]

#### Skills section

**Format:** [Simple / Categorized / Proficiency]
**Content:**
[Organized skills list]

#### Experience section

**Format:** [Standard / Functional / Hybrid]
**Bullets per role:**

- Recent: [N] bullets
- Older: [N] bullets

[Drafted entries, if requested]

#### Education section

**Include:**

- [Items to include]

**Exclude:**

- [Items to exclude]

#### Additional sections

**Recommended:** [Section name] because [reason]
**Skip:** [Section name] because [reason]

### Open questions

- [Facts the user still needs to supply or confirm, or "None"]
```
