# Technical skills section

## Layouts

Choose one. The technologies shown are placeholders: list only what the user
actually has.

**By category** (default; scannable and keyword-rich):

```
Languages: Python, JavaScript, TypeScript, Go, SQL
Frameworks: React, Node.js, Django, FastAPI
Databases: PostgreSQL, MongoDB, Redis, Elasticsearch
Cloud/Infrastructure: AWS (EC2, S3, Lambda, RDS), Docker, Kubernetes, Terraform
Tools: Git, JIRA, CI/CD, Datadog, Grafana
```

**By proficiency** (use carefully: the tiers are self-assessed, and a
"Familiar" line invites questions the user must be able to answer):

```
Expert: Python, React, PostgreSQL, AWS
Proficient: Go, TypeScript, MongoDB, Docker
Familiar: Rust, GraphQL, Kubernetes
```

**Flat list** (the safest for keyword parsing; use when space is tight):

```
Skills: Python, JavaScript, TypeScript, React, Node.js, Django, PostgreSQL, MongoDB, AWS, Docker, Kubernetes, Git
```

## What to include

| Category | Guidance | Typical entries |
| --- | --- | --- |
| Languages | Only those the user can code in confidently, ordered by relevance to the target role. Include query languages. | Python, Go, TypeScript, SQL, GraphQL |
| Frameworks and libraries | Group by area when the list is long. | Web: React, Vue, Angular, Django, Flask, Express. Data: Pandas, NumPy, TensorFlow, PyTorch. Testing: Jest, Pytest, Selenium |
| Databases | Cover the kinds the user has run in production. | Relational: PostgreSQL, MySQL, SQL Server. NoSQL: MongoDB, DynamoDB, Cassandra. Caching: Redis, Memcached |
| Cloud and DevOps | Name specific cloud services, not just the provider. | Cloud: AWS, GCP, Azure. Containers: Docker, Kubernetes. CI/CD: Jenkins, GitHub Actions, CircleCI. IaC: Terraform, CloudFormation |

## What to leave out

- Microsoft Office and similar assumed tools.
- Operating systems, unless the role is DevOps or systems work.
- Outdated technology, unless the job description asks for it.
- Skill bars and ratings: they are subjective and parsers cannot read them.
- Every technology the user touched once.
