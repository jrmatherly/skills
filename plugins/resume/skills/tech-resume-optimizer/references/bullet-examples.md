# Technical bullet examples

All numbers here are illustrative. Use only figures the user supplied or
confirmed.

## Metrics to ask about

| Kind | What to ask for | Phrasing |
| --- | --- | --- |
| Scale | Users | "serving 500K DAU" |
| Scale | Requests | "handling 10K requests/second" |
| Scale | Data | "processing 50TB daily" |
| Scale | Uptime | "maintaining 99.99% availability" |
| Performance | Latency | "reduced from X ms to Y ms" |
| Performance | Speed | "improved by X%" |
| Performance | Load time | "decreased by X seconds" |
| Efficiency | Cost | "reduced AWS costs by 40%" |
| Efficiency | Time | "cut deployment time from X to Y" |
| Efficiency | Resources | "reduced memory usage by X%" |
| Business | Revenue | "features drove $XM revenue" |
| Business | Conversion | "improved checkout by X%" |
| Business | Engagement | "increased DAU by X%" |

## Weak and strong

Weak:

```
- Worked on backend services
- Helped improve system performance
- Built features for the product
```

Strong:

```
- Architected microservices migration from monolith, reducing deployment time from 2 hours to 15 minutes and enabling independent team deployments
- Optimized PostgreSQL queries and implemented Redis caching, reducing API latency by 60% (from 500ms to 200ms) for 100K daily active users
- Built real-time notification system using WebSockets and AWS SNS, handling 1M+ messages daily with 99.9% delivery rate
```
