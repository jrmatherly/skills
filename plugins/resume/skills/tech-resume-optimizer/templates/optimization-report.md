# Tech resume optimization report

Follow this shape. Replace every bracketed placeholder; omit a section only
when it does not apply (for example, no GitHub link) and say so in one line.
A number that is an estimate or still needs the user's confirmation appears
in an improved bullet as a bracketed placeholder such as `[N]`, never as a
figure, and is listed with its basis under "Needs confirmation".

```markdown
# Tech resume optimization

## Technical skills restructure
**Current:** [Their current skills section]
**Optimized:**
Languages: [Ordered list]
Frameworks: [Ordered list]
Databases: [Ordered list]
Cloud/Tools: [Ordered list]

## Experience improvements

### [Company / Role]

**Current bullet 1:**
"[Original text]"

**Improved:**
"[Rewritten with action verb, technical what, scale/impact, technology]"

**Current bullet 2:**
[Continue for each bullet]

## Projects to highlight
[Which projects to keep, add or cut, and why, based on their background]

## GitHub recommendations
- [ ] [Pin X project (most relevant)]
- [ ] [Add READMEs to pinned repos]
- [ ] [Add profile README]

## Technical gaps to address
- [Missing skill] -> [How to address it in the resume or cover letter]

## Needs confirmation
- [Estimated or assumed figure] -> [What it was derived from]
```
