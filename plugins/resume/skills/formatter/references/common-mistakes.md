# Common formatting mistakes

## Mistakes and fixes

| Mistake | What it looks like | Fix |
| --- | --- | --- |
| Wall of text | Dense paragraphs, no bullets | Convert to bullets, keep any paragraph short |
| Inconsistent formatting | Fonts, sizes or styles change through the document | Pick one format per element and apply it everywhere |
| Creative template | Two columns with graphics, skill bars, proficiency charts, text in colored boxes | Single column, text-only skills list, simple bullets. Creativity goes in the portfolio |
| Too much information | Everything crammed onto one page | Cut by relevance to the target role; the user approves the cuts |
| Too little information | Half a page with wide margins | Add detail, bring margins down toward 0.5" |

## Pre-submission checklist

- One page, or two where experience warrants it
- Standard font, body text 10-12pt
- The same formatting for the same element throughout
- Clear, standard section headers
- Sensible white space
- No tables, text boxes or columns
- Contact details in the body, not the page header or footer
- Saved as `.docx` or text-based `.pdf`
- File named after the candidate
- Proofread for consistency: dates, bullet symbols, spacing, capitalization
