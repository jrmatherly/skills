# Section layouts

Plain-text layouts for each resume section. Names and details in the examples
are placeholders.

## Section header styles

Pick one style and use it for every header:

```
PROFESSIONAL EXPERIENCE
-----------------------
```

```
Professional Experience
_______________________
```

```
PROFESSIONAL EXPERIENCE
```

The rule under a header is a border or a line of characters, never an image.

## Contact block

Place it at the top of the body, not in the page header or footer, and not in
a table.

Recommended:

```
JOHN SMITH
john.smith@email.com | (555) 123-4567 | linkedin.com/in/johnsmith
San Francisco, CA
```

Alternative, when there are more links:

```
JOHN SMITH
San Francisco, CA
john.smith@email.com | (555) 123-4567
LinkedIn: linkedin.com/in/johnsmith | GitHub: github.com/johnsmith
```

Include:

- Full name
- Professional email address, without unusual special characters
- One phone number
- City and state
- LinkedIn URL
- Portfolio or GitHub, if relevant to the role

Exclude:

- Full street address
- Photo
- Date of birth
- Marital status
- A second phone number
- Personal social media

## Experience

Standard:

```
COMPANY NAME | City, ST
Job Title | Month Year - Month Year

- Achievement bullet with metrics and results
- Achievement bullet with metrics and results
- Achievement bullet with metrics and results
```

Alternative, title first:

```
Job Title
COMPANY NAME, City, ST                    Month Year - Month Year

- Achievement bullet with metrics and results
- Achievement bullet with metrics and results
```

Bullets per role: 3-6, more for recent roles and fewer for old ones. Bullet
wording and length belong to the **bullet-writer** skill.

## Dates

- Use one format throughout.
- Recommended: month and year, `Jan 2020 - Present`.
- Also acceptable: `01/2020 - Present`.
- Avoid full dates such as `January 15, 2020`.

## Skills

Simple list:

```
SKILLS
Python, JavaScript, SQL, React, Node.js, AWS, Docker, Git, Agile, JIRA
```

Categorized:

```
TECHNICAL SKILLS
Languages: Python, JavaScript, TypeScript, SQL
Frameworks: React, Node.js, Django, Flask
Tools: AWS, Docker, Kubernetes, Git, Jenkins
```

Columns:

```
SKILLS
Languages        Frameworks       Tools
Python           React            AWS
JavaScript       Node.js          Docker
SQL              Django           Git
```

Columns can be read out of order by a parser. Prefer the first two for
anything submitted through an online application; if the user wants columns,
tell them to test the parsed result first.

## Education

Standard:

```
EDUCATION
Bachelor of Science in Computer Science
University of California, Berkeley | 2018
GPA: 3.8/4.0
```

Include the GPA only when it is 3.5 or higher.

With honors or details:

```
EDUCATION
MBA, Finance & Strategy | Stanford Graduate School of Business | 2020
- Graduated with Distinction
- Relevant Coursework: Corporate Finance, M&A Strategy
```
