# Formatting review template

"not checked" for a setting that could not be inspected (for example fonts
when the resume was pasted as text).

- [ ] [Issue 2]
- [ ] [Issue 3]

### Document setup
- Margins: [current] -> [recommended]
- Font: [current] -> [recommended]
- Font sizes: [current] -> [recommended]
- Length: [current pages] -> [recommended pages]

### Section order
**Current:** [current order]
**Recommended:** [new order, and why]

### Visual improvements
- [Specific change 1]
- [Specific change 2]

### ATS compatibility fixes
- [Fix 1]
- [Fix 2]

### File
- Format: [current] -> [recommended]
- Name: [current] -> [recommended]

[Excerpt or description of the current formatting]

### After
[The same excerpt in the recommended formatting]
