# Edge cases

## Vague job descriptions

- Report the vagueness itself as a possible red flag.
- Extract whatever keywords the posting does contain.
- Recommend that the user ask the recruiter or hiring manager for clarity
  before applying.
- Use the standard requirements for that role in that industry as the
  baseline for scoring, and say that the score rests on that assumption.

## Several roles in one posting

- Separate the core role from the "other duties".
- Score the match against the primary responsibilities only.
- Flag the scope-creep risk.

## Internal postings (the user already works there)

- Change the strategy: emphasize internal knowledge.
- Highlight cross-team relationships.
- Reference specific company initiatives the user has been part of.

## Reposted jobs

- A repost may mean the previous hire didn't work out, the role expanded, or
  the first search failed.
- Still worth applying; recommend finding out why it was reposted.
- Compare the requirements with the original posting if the user has it.
