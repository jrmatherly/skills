# Requirement classification

How to sort a posting's requirements and keywords, and how to tell a
dealbreaker from a gap worth applying through.

## Requirement classes

- **Required (must-have):** education, years of experience, specific
  technical skills, certifications and licenses, industry experience.
- **Preferred (nice-to-have):** "bonus" skills, advanced certifications,
  domain expertise, experience with a specific tool.
- **Soft skills and culture:** communication style, work environment, team
  structure, company values.

## Wording that signals the class

Required:

- "Must have ..."
- "Required: X years of ..."
- "You have ..."
- "Essential qualifications"
- Listed under a "Requirements" heading
- Mentioned three or more times in the posting

Preferred:

- "Nice to have ..."
- "Bonus if you have ..."
- "Preferred qualifications"
- "Ideally, you'd have ..."
- "A plus if ..."
- Mentioned only once or twice

## Keyword groups

- **Hard skills** (technical abilities)
  - Tools: Salesforce, Python, AWS, Excel
  - Methodologies: Agile, Six Sigma, SDLC
  - Certifications: PMP, CPA, AWS Certified
- **Soft skills** (interpersonal): leadership, collaboration, communication,
  problem-solving, critical thinking, adaptability, initiative
- **Industry and domain knowledge**: B2B SaaS, healthcare, fintech;
  enterprise vs SMB; regulatory knowledge (HIPAA, SOX, GDPR)

Record each keyword in the posting's exact wording and with its mention
count, so the tailoring plan can quote it.

## Dealbreakers

Treat as a critical gap and recommend not applying:

- A required license the user doesn't hold (medical, legal, CPA)
- A required clearance the user can't obtain
- Years of experience 50% or more below the requirement
- A degree the posting states as required and the user doesn't have
- A location requirement the user can't meet

Not dealbreakers; recommend applying anyway:

- Experience slightly below the ask (3 years when the posting wants 5)
- A "preferred" degree the user doesn't have
- Nice-to-have tools or skills that can be learned
- Missing industry experience when the user has transferable skills
