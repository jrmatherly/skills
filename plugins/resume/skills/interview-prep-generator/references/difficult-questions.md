# Difficult questions

Formulas and sample answers. The samples show the shape; write the user's
answers from their own history.

## "What's your greatest weakness?"

Formula: a real weakness + self-awareness + the steps taken to improve.

```
"I tend to be overly detail-oriented, which can sometimes slow me down. I've
recognized this and now set time limits for tasks and ask for feedback on
when good enough is good enough. In my current role, I've also learned to
delegate detailed work when appropriate."
```

The sample shows the shape only. Ask the user for a weakness that is real for
them; a strength in disguise reads as evasion.

## "Why are you leaving your current job?"

Keep the answer:

- Positive: about growth
- Forward-looking: not a list of complaints
- Brief: don't over-explain
- True: the reason given is the real one. Ask the user why they are leaving
  or left before drafting.

```
"I've learned a lot at [Current Company], but I'm looking for [specific
opportunity] that I don't see available in my current path. This role at
[New Company] offers exactly that - the chance to [specific thing]."
```

If the user was laid off or let go, say so plainly in one sentence and move
to what comes next. Never present it as a voluntary move.

```
"My role was eliminated when [Company] cut [team or number of roles] in
[month]. Since then I've [what the user has actually done], and this role
fits because [specific reason]."
```

## "Tell me about a time you failed"

Must include:

- A real failure, not a humble brag
- What was learned
- How the learning was applied afterwards

```
"In my first year as a PM, I launched a feature without sufficient user
research. The feature was technically sound but users found it confusing.
Only 10% adopted it. I learned the hard way that building the right thing
matters more than building the thing right. Since then, I never skip user
research - I now always do at least 10 user interviews before major feature
decisions."
```

## Salary questions

Deflect until an answer is required:

```
"I'm flexible on compensation and more focused on finding the right role.
Can you share the range budgeted for this position?"
```

If pressed:

```
"Based on my research and experience, I'm looking for something in the range
of $X-$Y, but I'm open to discussing the full compensation package."
```

The range comes from current market research, not from this file.

## The user's own concerns

For a gap, a short tenure or a career change, use the same shape as the
weakness answer: state the fact plainly, give the reason in one sentence, and
move to what it taught or enabled and why it makes the user a fit now.
