# Version status report template

A snapshot built from the master, the files and the tracker as they are when
the report is written. Repeat the role-type block for each role type in use.
Fill counts and dates from the files; write "Unknown" where something could
not be checked.

```markdown
# Resume version management

## Master resume status

**Last updated:** [Date from the master]
**Location:** [File path]
**Total experience entries:** [N]
**Total bullet points available:** [N]

## Active versions

### Role type: [Role type]

**Base version:** [File name]

**Tailored versions:**

| Company | File name | Date created | Status |
| ------- | --------- | ------------ | ------ |
| [Company] | [File name] | [Date] | [Status from the tracker] |

## Pending updates

Found during this review:

- [ ] [Achievement, project or certification not yet in the master]
- [ ] [Version sent but missing from the tracker]
- [ ] [Version older than about six months to archive]

## Recommended actions

1. [Action]
2. [Action]
```
