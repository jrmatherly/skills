# Master resume template

The master is a working document, not a submission: no page limit, every
bullet kept. Use this structure and update `Last updated` on every edit.

```markdown
# Master resume - [Name]

Last updated: [Date]

## Contact information

[Full contact details]

## Professional summary versions

**[Role type A]:** [Summary]
**[Role type B]:** [Summary]
**[Role type C]:** [Summary]

## All skills

### Technical skills

[Complete list, by category]

### Soft skills

[Complete list]

### Industry knowledge

[All domains]

## Professional experience

### [Company] | [Title] | [Dates]

**All bullets (choose the best for each application):**

- [Bullet] (leadership focus)
- [Bullet] (technical focus)
- [Bullet] (results focus)
- [Bullet] (collaboration focus)
- [Additional achievement]
- [Additional achievement]

**Keywords this experience covers:** [Keywords this role demonstrates]

### [Previous company] | [Title] | [Dates]

[Same format]

## Education

[Complete education history]

## Certifications

[All certifications earned, with issuer and year]

## Projects

[All notable projects]

## Volunteer and additional

[All other relevant experience]
```
