# Tailored resume changes template

Report every change in this shape. Repeat the experience block for each role
that changed. Write "No change" for a section left as it was.

```markdown
# Tailored resume changes

## Target: [Job title] at [Company]

**Match score before tailoring:** [From the job-description-analyzer report]

### Professional summary

**Before:** [Original]
**After:** [Tailored version]
**Keywords added:** [List]

### Skills section

**Previous order:** [List]
**New order:** [Reordered list]
**Added:** [Keywords from the posting that the user has]
**Removed:** [If any, for space]

### Experience changes

**[Company] - [Title]**

- Lead with: [bullet moved to position 1]
- Modified: [Before] -> [After]
- Keyword added: "[phrase]" in [which bullet]
- De-emphasized: [bullet moved down, or removed for space]

### Other adjustments

- Education: [relevant coursework added, or "No change"]
- Certifications: [any highlighted]
- Projects: [any included]

### Open questions

- [Facts or numbers the user still needs to confirm, or "None"]

### Overall changes summary

- Keywords added: [N]
- Bullets modified: [N]
- Sections reordered: [Yes / No]
- Requirements visibly evidenced: [N] of [M] before, [N] of [M] after
```
