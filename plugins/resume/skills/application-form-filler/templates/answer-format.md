# Answer format

Wrap each answer in a plain code block so it copies cleanly into the form.
Put nothing but the answer inside the block.

For a single field:

```
[Answer text]
```

For several fields, use one code block per field with the field's label in
bold above it:

**Years of React experience:**

```
4 years. Used it across Screenr (agentic hiring SaaS), a Tauri-based POS
system, and several client projects. Also used Next.js where SSR was needed.
```

**Describe your backend experience:**

```

```

For a rating or dropdown field, give the option to select and one line on why
that level is accurate.

After the blocks, list anything the user must confirm before submitting:
estimates, assumed years, or facts not found in their CV.
