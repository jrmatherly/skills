# Negotiation strategy output

Produce the plan in this shape. Leave a value as "to confirm" when it hasn't
been researched or supplied; never fill it with a guess.

```markdown
# Salary negotiation strategy

## Market research summary

**Role:** [Title]
**Location:** [City/Remote]
**Experience level:** [Years]

**Market range:**

- 25th percentile: $XXX,XXX
- 50th percentile: $XXX,XXX (target)
- 75th percentile: $XXX,XXX
- 90th percentile: $XXX,XXX (stretch)

**Sources:** [Each source used, with the date of its data]

## Their offer

| Component    | Amount   |
| ------------ | -------- |
| Base         | $XXX,XXX |
| Bonus        | X%       |
| Equity       | $XXX,XXX |
| Signing      | $XXX     |
| Benefits     | $XXX     |
| Total year 1 | $XXX,XXX |
| Total ongoing | $XXX,XXX |

## Your counter

| Component | Ask      | Justification |
| --------- | -------- | ------------- |
| Base      | $XXX,XXX | [Why]         |
| Signing   | $XXX     | [Why]         |
| [Other]   |          |               |

## Counter-offer script

[Email or call script customized for this situation]

## If they push back

**Plan B:** [Alternative elements to negotiate]
**Walk-away point:** [The user's minimum]

## Key talking points

1. [Experience or value point]
2. [Market data point]
3. [Specific achievement]

## Questions to clarify

- [Equity vesting schedule?]
- [Is the bonus guaranteed?]
- [Review cycle timeline?]

## Confirm with a professional

- [Tax, legal or contract points that apply, or "None identified"]

This plan is preparation help, not tax, legal or financial advice.
```
