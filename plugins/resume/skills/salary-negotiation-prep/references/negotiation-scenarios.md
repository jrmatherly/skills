# Negotiation scenarios

`$X` and `$Y` are placeholders for the user's researched numbers.

## 1. The first offer is low

- Don't accept immediately
- Express enthusiasm for the role
- Counter with a research-backed number
- Be ready to justify it

```
"I'm thrilled about the opportunity. The base salary is lower than I
expected based on my research. For this role and market, I was expecting
something in the $X-$Y range. Is there room to move closer to $X?"
```

## 2. They ask for salary expectations first

Deflect:

```
"I'm flexible and focused on finding the right fit. What's the range you've
budgeted for this role?"
```

If pressed:

```
"Based on my research for this role and market, I'm looking at $X-$Y, but
I'm open to discussing the full compensation picture."
```

## 3. They won't move on base

Negotiate something else. Everything below is negotiable:

- Signing bonus (one-time, so often easier to approve)
- Annual bonus or commission terms
- Additional equity
- Benefits
- An earlier performance review, for a sooner raise
- More vacation days
- Remote work flexibility
- Professional development budget
- Title upgrade
- Relocation assistance
- Start date

```
"I understand the base salary is firm. Could we discuss a signing bonus to
help bridge the gap? Something in the range of $X would make this work."
```

## 4. The user has competing offers

- Mention them only if they are real
- Don't make it a threat
- Frame it as a problem to solve together

```
"I want to be transparent - I'm also in discussions with [another company /
a few other companies]. They're offering $X. [This Company] is my first
choice because [genuine reason], but I want to make sure the compensation is
competitive."
```

## 5. They ask about current salary

Some jurisdictions ban employers from asking about salary history. The rules
differ by place and change over time, so check the current law for the user's
location or tell them to; don't state that the question is illegal without
checking.

Redirect to the role's value:

```
"I'd prefer to focus on the value I'd bring to this role and what the market
rate is. What's the range you've budgeted?"
```

Or explain why the comparison doesn't hold:

```
"My current compensation isn't really comparable since [different location /
role / structure]. Based on my research for this role, I'm targeting $X-$Y."
```

If the user chooses to answer, the number they give must be true.
