# Academic CV output template

Produce the result in this shape: the recommended order first, then the
formatted sections in that order, then the notes and the open items. Include
every section that has content.

```markdown
# ACADEMIC CV STRUCTURE FOR [NAME]

## Recommended Section Order
[Based on position type and field]

1. [Section]
2. [Section]
...

## Section Content

### Education
[Formatted education section]

### Publications
[Formatted with appropriate style for field]

### [Other Sections]
[Formatted content]

---

## Formatting Notes
- [Field-specific conventions to follow]
- [Style guide recommendations]

## Things to Add/Update
- [ ] [Missing item]
- [ ] [Item needing update]
```
