# Creative portfolio resume

Creative professionals want the resume itself to show their craft, but most
online applications pass through parsing software that heavily designed files
break. Resolve the conflict with two versions of the same content: an
ATS-compatible one and a designed one.

Before producing output, read
[templates/resume-strategy.md](templates/resume-strategy.md) and follow it.

## Inputs to gather

- Discipline (graphic design, UX/product design, marketing/brand, writing/
  content, photography/video) and setting (agency, in-house, freelance).
- The current resume and target roles.
- How each application will be submitted: portal, job board, direct email,
  in person.
- Portfolio URL, the case studies worth linking, and whether the site has or
  needs a resume page.
- Existing personal brand: fonts, colors, logo or mark.
- The tools the user works in.

## Truthfulness

Both versions carry the same facts. Never invent employers, titles, dates,
clients, metrics or skills, and never let the designed version claim more
than the ATS one. Estimated numbers must be derived from facts the user gave,
labelled as estimates and confirmed with the user before they go into either
document.

## Which version goes where

| Use the ATS-compatible version when | Use the designed version when |
| --- | --- |
| Applying through an online portal | Handing it out at networking events |
| Submitting to a job board | Emailing a hiring manager directly |
| Software will parse the resume | Publishing it on the portfolio site |
| Unsure how the file will be processed | Bringing it to an in-person interview |
| | Applying to a creative agency that expects a visual resume |
| | Told explicitly that no ATS is used |

When in doubt, send the ATS-compatible version.

## ATS-compatible version

Build this version to the **formatter** skill's ATS-safe rules, with no
exceptions for creative roles: the columns, icons, skill bars and display
fonts a designer reaches for first stay in the designed version. Here,
creativity shows through restraint:

- Deliberate white space and consistent, intentional spacing.
- A clean typographic hierarchy in an ATS-safe professional font, with
  strategic bold and italic.
- Simple line dividers between sections.
- Sparing color in the name and headers.
- Thoughtful content organization and strong copywriting.
- A hyperlink to the portfolio.

## Designed version

Three principles, in priority order when they conflict:

1. **Clarity over cleverness.** Information must still be findable and
   readable. Experimental design belongs in portfolio pieces, not here.
2. **Show, don't just tell.** The resume is a design sample: type choices,
   layout and detail demonstrate design thinking and attention to craft.
3. **Brand consistency.** Match the portfolio site: same palette, same
   visual identity.

Specify each of these in the output:

- **Typography:** a headline font with personality, a readable body font, a
  size hierarchy (name > sections > body), line height and letter spacing.
- **Color:** a brand color for accents, high contrast for text, 2-3 colors at
  most, print-friendly choices.
- **Layout:** two columns are acceptable in this version only; strategic
  white space, clear hierarchy, consistent margins and gutters.
- **Visual accents:** icons (used consistently or not at all), dividers and
  rules, subtle background elements, a logo or personal mark.

For the typography, layout and color checklists and the choice of design
tool, see [references/design-execution.md](references/design-execution.md).
For what each creative discipline must demonstrate and how its resume should
approach that, see
[references/field-guidance.md](references/field-guidance.md).

## Portfolio integration

Put the portfolio link in the header of both versions, and link individual
bullets to the work behind them:

```
Portfolio: yourname.com

- Redesigned checkout flow, increasing conversion by 40%
  Case Study: yourname.com/checkout
```

To write the case studies those links point to, use the
**portfolio-case-study-writer** skill.

For a resume page on the portfolio site, the options are a PDF download of
the designed version, an HTML resume page, an interactive resume, or a
combination. Recommend at least the PDF download, a responsive web version if
there is one, and updating the page whenever the main resume changes.

## Process

1. Gather the inputs and identify the discipline and setting.
2. Decide which version each planned application needs.
3. Settle the content once; it feeds both versions. Note the content
   adjustments the discipline calls for.
4. Specify the ATS-compatible version (.docx and .pdf).
5. Specify the designed version (print-quality .pdf): typography, color,
   layout, accents.
6. Plan the portfolio links and resume page.
7. Run the checks below.

## Before finishing

- Both versions exist in the plan and carry identical facts.
- The design demonstrates skills relevant to the target role.
- Content is still clear and scannable at a glance.
- The portfolio is prominently linked.
- Visual identity is consistent with the portfolio.
- Typography is professional; colors are accessible and print-friendly.
- The designed file is a reasonable size for sharing.
- Content quality matches design quality: the resume is a worthy portfolio
  piece.
