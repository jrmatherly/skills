# Guidance by creative field

For each discipline: what the resume has to demonstrate, and how to approach
the resume so that it does.

| Field | Must show | Resume approach |
| --- | --- | --- |
| Graphic design | Typography skills; layout and composition; visual hierarchy; attention to detail | The resume is a portfolio piece. Clean, sophisticated design; show range through subtle choices; link to the portfolio for variety. |
| UX / product design | Information architecture; user-centered thinking; clear visual hierarchy; a systematic approach | Scannable, organized structure; clear content hierarchy; organized around the reader (the recruiter) as the user; link to case studies. |
| Marketing / brand | Brand thinking; storytelling; strategic communication; attention to audience | On-brand visual identity; compelling narrative flow; strategic content choices; proof points for every claim. |
| Writing / content | Writing quality; editing precision; clear communication; voice and style | Impeccable copy; strong bullets; zero errors; personality carried by the writing, not the layout. |
| Photography / video | Visual eye; production quality; technical skill; aesthetic sensibility | Clean, uncluttered design; a strong portfolio link; quality over quantity; let the portfolio speak. |

Use the "must show" column to pick the content adjustments for the strategy
output, and the "resume approach" column to set how far the designed version
goes.
