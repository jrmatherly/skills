# Design execution

Checklists for specifying or reviewing the designed version, and the tools it
can be built in.

## Typography checklist

- [ ] Name is the largest element
- [ ] Clear hierarchy (3-4 levels at most)
- [ ] Body text is at least 10-12pt
- [ ] Line height allows breathing room
- [ ] No more than 2 font families
- [ ] Fonts complement each other

## Layout checklist

- [ ] Clear sections and flow
- [ ] Consistent margins throughout
- [ ] Adequate white space
- [ ] Elements align to a grid
- [ ] Visual balance achieved
- [ ] Scannable at a glance

## Color checklist

- [ ] Limited palette (2-3 colors)
- [ ] High contrast for text
- [ ] Accessible color choices
- [ ] Prints well in black and white
- [ ] Consistent with personal brand
- [ ] Professional appearance

## Tools

Recommend from what the user already works in.

| Tool | Notes |
| --- | --- |
| Adobe InDesign | Best for layout |
| Figma | Good for web-native work |
| Adobe Illustrator | Vector-based |
| Sketch | Mac only |
| Canva | Simpler; templates available |
| Google Docs | Limited, but ATS-safe |
| Microsoft Word | More capable than expected |

Steer away from:

- PowerPoint or Keynote: not built for document layout.
- Unvetted online resume builders.
- Heavy templates that obscure the content.
